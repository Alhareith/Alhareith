06 / Core Engineering Principles
> [!TIP]
>  * Understand Before Implementing: Never solve a poorly defined problem.
>  * Architecture Over Complexity: Start simple; add abstraction only when required.
>  * Evidence Over Assumptions: Benchmark performance; evaluate AI models systematically.
>  * Failures Are Data: Use bugs and model errors to uncover invalid assumptions.
>  * Document Decisions: Record what was chosen, why, and what trade-offs were accepted.
