## Engineering Process

I follow a simple process: understand the problem, design a clear solution, build it, measure the result, and improve it.

```mermaid
flowchart LR
    A[Problem] --> B[Understand]
    B --> C[Design]
    C --> D[Build]
    D --> E[Measure]
    E --> F[Improve]
    F -.-> A
```
